# Barangay Management System

This workspace contains the initial scaffolding for a barangay management system with:

- `frontend/` - React + Vite public website and resident portal UI
- `backend/` - Node.js + Express API server

## Next steps

1. Install backend dependencies:
   - Open `backend` and run `npm install`
2. Install frontend dependencies:
   - Open `frontend` and run `npm install`
3. Start development servers:
   - Backend: `npm run dev` from `backend`
   - Frontend: `npm run dev` from `frontend`
